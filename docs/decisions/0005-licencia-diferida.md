# 0005. Licencia diferida

- **Estado:** Aceptada
- **Fecha:** 2026-10-22

## Contexto
Vekipper es público en GitHub, pero todavía no está decidido su futuro (por ejemplo, si habrá un SaaS). La licencia condiciona lo que otros pueden hacer con el código.

## Decisión
Se publica sin licencia por ahora.

## Consecuencias
- Legalmente, sin licencia el código queda con "todos los derechos reservados": se puede ver, pero nadie tiene permiso para usarlo, modificarlo ni redistribuirlo.
- Las contribuciones externas quedan en pausa hasta definir la licencia, para no complicar un cambio posterior.
- Opciones a evaluar cuando toque: **MIT** (máxima libertad, también para que otros hagan un SaaS) o **AGPL-3.0** (quien lo ofrezca como servicio debe publicar su código).
